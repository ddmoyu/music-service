# 酷我非 VIP Cookie 对照测试

测试日期：2026-10-23；环境：Windows；对应工作区 0.1.7。用户确认账号不是 VIP，本次也通过官网会员查询验证。范围为接口探测和音频对照，没有修改酷我生产适配器，也没有将 Cookie 登录标记为已实现。

**结论：Cookie 有效，但在本次样本中没有提升下载音质，也没有扩展公共搜索、排行榜或歌手目录的访问范围。歌手目录和专辑封面存在可用的匿名端点，属于本项目可以补接的功能。**

## 凭证与会员状态

Cookie 保存在 `.local-secrets/kuwo-cookie.txt`，该目录被 Git 忽略。原始响应仅保存在被忽略的 `out/kuwo-cookie-probe/`，其中可能包含账号资料或临时签名地址，不应提交。本文不记录账号、会话值或音源签名。

| 检查 | 结果 | 判断依据 |
| --- | --- | --- |
| 官网账号资料查询 | ☑ 有效 | `GET /vip/v2/sysinfo?op=gui` 使用本地 Cookie 中的账号和会话参数，返回匹配的账号资料 |
| 去掉会话的对照 | ☑ 已验证 | 相同账号、`sid=0` 且不带账号 Cookie 时，返回 `data=null`；完全匿名也返回空资料 |
| 会员状态查询 | ☑ 当前无有效权益 | 官网 `POST /vip/v2/user/vip` 的只读 `op=ui` 查询中，豪华 VIP、音乐包、SVIP 等到期字段均不晚于服务端当前时间 |
| 本项目 Cookie 管理能力 | ☐ 未接入酷我 | 上述验证由本地探测完成；当前酷我适配器仍使用匿名请求 |

这里以实际账号资料及会话对照判定有效性，没有将 HTTP 200 或网页显示头像作为登录成功证据。

## 音质对照

使用当前适配器的 `mobi.kuwo.cn/mobi.s` 请求方式，对每首歌曲分别请求 `128kmp3`、`320kmp3`、`2000kflac`。两组使用相同歌曲 ID、档位和客户端标识，区别仅为解析请求是否携带用户 Cookie。后续 CDN 请求均不携带账号 Cookie。

共 3 首 × 3 档 × 2 组，即 18 次解析及音频前缀读取。每个成功响应读取前 65,536 字节，检查 MP3 帧头或 FLAC STREAMINFO，同时比对服务器给出的完整文件大小。

| 歌曲 | 标准请求，两组结果 | 高品质请求，两组结果 | 无损请求，两组结果 | Cookie 提升 |
| --- | --- | --- | --- | --- |
| 周杰伦《晴天》`228908` | MP3 128 kbps／44.1 kHz | MP3 320 kbps／44.1 kHz | FLAC 24 bit／44.1 kHz／双声道 | 未发现 |
| 《恒星不忘 Forever Forever》`661608480` | MP3 128 kbps／44.1 kHz | MP3 320 kbps／44.1 kHz | FLAC 24 bit／48 kHz／双声道 | 未发现 |
| 蓝心羽《晴天》`78932517` | MP3 128 kbps／44.1 kHz | 上游返回 `mgg`，不是可验证的 MP3 | 上游返回 `mgg`，不是可验证的 FLAC | 未发现，Cookie 没有使其变为可用目标格式 |

9 组对照的音频前缀 SHA-256 及完整文件大小均相同。上游标为 `mgg` 的两个请求没有作为高品质或无损成功样本，也没有据其 `bitrate` 字段推断音质；本次没有解密或转换该格式。

另外，对周杰伦《晴天》的两组 FLAC 分别完整读取并计算哈希，结果如下：

| 检查项 | 匿名解析 | Cookie 解析 |
| --- | --- | --- |
| 完整文件字节数 | 55,397,039 | 55,397,039 |
| 实际音频参数 | FLAC／24 bit／44,100 Hz／2 声道 | 相同 |
| STREAMINFO 时长 | 269,747 ms | 相同 |
| 完整 SHA-256 | `45d2073bbe60910d87e77f9f5eb87951b36a24a7da1492c7f0e7a3d5e7dd38c2` | 相同 |

这说明该样本两次取得的完整文件逐字节一致。24 bit／44.1 kHz 和 24 bit／48 kHz 在当前项目中均记录为 lossless，不据此新增 Hi-Res 能力。结果仅适用于本次账号、样本及测试时的上游行为，不代表全部曲库或不同音源端点具有相同权限。

## 证据与边界

- 当前原生请求构造：[`src/providers/kuwo/protocol/requests.cpp`](../../src/providers/kuwo/protocol/requests.cpp)。
- 端点与请求头来自测试时的[酷我官网](https://www.kuwo.cn/)客户端；账号／会员查询来自[酷我会员官网](https://vip1.kuwo.cn/vip/added/vip_2016/index.jsp)加载的 `userinfo.js`、`super.js`。
- 本机脱敏汇总：`out/kuwo-cookie-probe/comparison.json`、`followup.json`、`evidence-summary.json`、`cover-summary.json`；仅本地留存，不随仓库交付。
- 本次没有重跑服务端任务持久化、标签写入、侧文件、复用或重启全链路，也没有重新构建 C++ 或执行全量单元测试。此次新增的是协议和下载文件对照证据，不替代此前 Windows 闭环验收。
