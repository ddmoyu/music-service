# 咪咕首阶段 Windows 验收

日期：2026-10-23。首阶段验收基于 `migu-native 0.1.10`、服务版本 `0.1.14`；后续 `0.1.11` 代码审查修复见文末，`0.1.12` 原生 Z3D 支持见 [Z3D 实现记录](migu-z3d.md)。首阶段已完成目录、标准整曲下载和文件回读闭环；不表示咪咕全部音质、账号与加密格式均已支持。

实现和端点说明见[咪咕适配器](../../src/providers/migu/README.md)，可重复运行的公共 API 客户端为 [migu_e2e.py](../../packaging/e2e/migu_e2e.py)。生产使用原生 C++，不调用外部下载工具、第三方解析服务或 Python 协议实现。

| --- | --- |

| 咪咕专项 | 19 个用例、747 条断言全部通过；其中 18 个适配器用例、1 个静态 WebP 结构用例 |

## 整曲、元数据与文件验证

标准品质样本为汪苏泷《巴赫旧约》，`contentId=600902000008861771`。客户端先通过歌曲搜索找到该内容 ID，再请求详情、歌词、音源并创建持久下载任务。

| 检查 | 结果 |
| --- | --- |
| 匿名整曲 | 官方接口判定 `full`；实际 MP3 通过公共音频验证，任务 `completed`，无错误、无警告 |
| 实际品质 | `standard`；不是仅取得 URL，已下载、处理并发布完整文件 |
| 标题与标签 | 标题与详情一致；标题、歌手、专辑、曲号、歌词和封面状态均为 `written`；检查了实际 ID3 的标题、APIC 和 USLT 帧 |
| WebP 封面 | 内嵌 MIME 为 `image/webp`；独立封面响应同样为 `image/webp`，RIFF 头正确；内嵌图片与导出文件字节一致 |
| 歌词侧文件 | 独立歌词可以通过文件票据读取，状态 `lyrics_file=written` |
| Range | `bytes=0-15` 返回 206，内容与发布文件对应片段一致 |
| 结果复用 | 不同幂等键、相同下载意图复用同一已完成任务 |
| 重启回读 | 重启本次临时服务后重新签发票据，音频、封面和歌词的 SHA-256 均与重启前一致 |

发布 MP3 为 **3,644,579 字节**，SHA-256：

```text
f59f6c158dd5d95f2faa5b00741414586c3b2059d65c73c41517d344961033cc
```

封面 SHA-256 为 `19d449476da4bc735f51cf221f45e793c63e70b90eef1c59aac6b9e52bfb2e10`；歌词 SHA-256 为 `386ad536c3840c57808e9061c6ef9d90ecb510eacabcb9e55ec328490b0619a6`。

WebP 检查有容器和块边界限制，拒绝动画与异常结构，不进行像素解码或转码。播放器能否显示 WebP 内嵌图片取决于播放器自身支持。

## 权限与未覆盖范围

- 当前匿名样本严格 `high` 和 `lossless` 均返回 `CREDENTIALS_REQUIRED`；显式 `allow_lower` 返回 `standard`。高品质／无损候选映射和成功响应已有离线测试，尚无真实成功下载证据。
- 《晴天》`600902000006889366` 的试听资源在默认策略下返回 `PREVIEW_REJECTED`。可访问的 URL、正常扩展名或较大文件都不能替代整曲权限证据。
- `hires` 严格请求返回 `QUALITY_UNAVAILABLE`。加密资源不进入未实现的解密流程，不改写官方音源路径猜测更高品质。
- 可选 `web_cookie` 仅用于取流请求；本轮未使用真实咪咕账号，不声明 Cookie 有效性校验、会员／购买权限或个人歌单已完成。
- 歌手目前仅支持搜索；详情、歌曲／专辑目录，以及翻译、逐字、罗马音歌词未接入。旧版版权 ID 歌曲链接和短链不支持，具体支持形式见适配器文档。
- 本轮只验证 Windows MSVC x64 Debug，未验证 Release 发行包、Windows 系统服务、Linux、macOS、Docker 或 NAS。没有提交、推送或发布。

本地证据位于 Git 忽略的 `out/migu-build-verified.log`、`out/migu-unit-final.log`、`out/migu-ctest-final.log`、`out/migu-live-final.log` 和 `out/migu-live-final-report.json`。最终报告不含 Cookie、账号标识或带签名的音源 URL。

## 2026-10-23 代码审查修复

本轮将适配器版本更新为 `migu-native 0.1.11`。在修改实现前新增回归用例，旧实现出现 3 个咪咕测试用例失败（8 个断言）和 1 个媒体刷新测试用例失败（12 个断言），证明以下问题可复现：

| 问题 | 修复行为 |
| --- | --- |
| 试听时长只读取响应级字段，可能忽略歌曲条目时长、被零值覆盖，或沿用整曲时长 | 读取两处正时长，缺少片段证据时保持未知，超过一天的异常值明确失败 |
| 音源刷新后只检查歌曲、音质和容器，旧票据可能继续保留整曲／未加密状态 | 同时比较完整性和处理计划；变为试听、未知或需要解密时，使旧资源和票据失效，不请求新 CDN 地址 |
| 显式允许降低音质时，加密候选会提前终止，错过低档位普通音源 | 继续按 `SQ → HQ → PQ` 查询官方权限接口；严格策略不降级，不尝试解密或改写地址 |
| 已知总数与固定窗口实际条目数不符时，可能跳过缺项或提前结束 | 返回上游响应错误；真实空结果和明确空槽仍按原语义处理 |

再次匿名请求官方接口确认：《巴赫旧约》的 `PQ` 返回整曲、`needEncrypt=0`；`HQ`、`SQ` 返回 `cannotCode=440003`。《晴天》返回 `auditionsLength=60`、试听类型 `04`，同一响应还带有 `formatType=Z3D` 及文件密钥字段的特殊音源描述。这说明普通 MP3 与加密音源分支可以同时存在，不能依据普通音源的 `needEncrypt=0` 推断其他格式都不加密。本轮未下载或解密 Z3D，也未使用真实账号验证会员权限。探测报告只保存字段、格式和密钥是否存在，不保存密钥值或签名 URL。

修复后使用独立 MSVC x64 Debug 构建（服务 `0.1.20`，平台清单 `kuwo;fivesing;netease;qq;migu`）完成验证：

- 构建成功，无项目编译或链接错误；咪咕改动文件通过格式检查。
- 全量 CTest 共 458 项：**452 通过、6 按条件跳过、0 失败**，耗时 179.46 秒。包括 22 项咪咕／静态 WebP 专项，以及新增的媒体地址刷新集成测试。6 项跳过仍为 5sing、酷我、网易云条件在线探测、外部 MP3 样本及公共 HTTPS 探测。
- 在线 E2E 报告 `passed`：显式 `allow_preview=true` 后仍保留 `preview` 与 `PREVIEW_RESOURCE`，代理读取 `bytes=0-1023` 返回 206、1,024 字节和 `audio/mpeg`；默认请求仍拒绝试听。此处验证片段字节读取，不将其视为整曲权限或试听时长裁剪验证。
- 标准整曲下载完成，无错误和警告；MP3 字节数、音频／封面／歌词 SHA-256 与首阶段一致；标题、艺术家、专辑、封面、歌词、曲号写入通过，Range、复用、重启回读均通过。
- 高品质、无损仍在匿名样本上返回 `CREDENTIALS_REQUIRED`，允许降低音质后取得 `standard`；Hi-Res 返回 `QUALITY_UNAVAILABLE`。没有使用账号、执行解密、提交、推送或发布。
