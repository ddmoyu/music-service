**酷我同时支持按歌手名搜歌曲，以及返回歌手实体的专用搜索。** 0.1.8 已接入歌手详情、歌曲和专辑分页，并支持 `/singer_detail/336/info` 等歌手链接。匿名在线验收读取了周杰伦（336）和林俊杰（1062）的资料，完整遍历周杰伦歌曲 18 页／1,708 首、专辑 5 页／45 张，实际数量与上游 total 一致，无重复 ID。资料缺失保持 null，关键词搜索不保证等于歌手完整目录。

[酷我歌手与封面验收](research/kuwo-artists-acceptance.md)还验证了《晴天》（228908）的标准 MP3、FLAC：封面内嵌、独立图片、原图三者字节一致，完成结果复用与重启回读通过。另一首没有专辑身份的歌曲保持无封面。歌曲和歌手详情直接请求 `wapi.kuwo.cn` JSON API，旧 HTML 解析路径已移除。

此前的[非 VIP Cookie 对照测试](research/kuwo-cookie-evaluation.md)确认会话有效，但所测音质没有提升；本轮新增能力均匿名可用，不需要 Cookie。Cookie 继续只保存在 Git 忽略的本地目录，个人歌单仍未接入。

随后使用用户提供的新 Cookie 完成[会员账号音质复测](research/kuwo-membership-quality-retest.md)：会员有效至 2026-11-23，接口与用户均确认为豪华 VIP；首轮现有三档的 9 组音频对照仍与匿名相同，完整 FLAC 哈希一致。首轮扩展参数取得的 MFLAC／MGG 未解密和验证。

随后指定的梅艳芳《亲密爱人（黑胶版）》492445332，普通无损为 16 bit／44.1 kHz，黑胶为 24 bit／96 kHz；匿名与豪华 VIP 的完整黑胶文件哈希相同。**0.1.9 已接入原生黑胶下载与尾部处理**，通过统一 `hires` 选项请求，逐帧 CRC／PCM MD5 校验后清理附加数据，再次验证最终带标签文件；严格品质、标签与封面、结果复用、Range 与重启回读通过，详见[黑胶接入验收](research/kuwo-vinyl-acceptance.md)。

表中歌词、封面和译文勾选表示支持获取该内容，具体歌曲仍可能缺失。酷我、5sing 的歌单／专辑展示图片与下载单曲的可信封面是不同字段，不能互相冒用。链接解析只覆盖各适配器已列明的形式，不代表支持全部短链和移动端分享链接。

5sing 未勾选的目录能力在当前参考协议中未提供或明确 unsupported，本轮不以空接口代替实现。所有平台的公共推荐均不等同于登录后的个性化每日推荐。
